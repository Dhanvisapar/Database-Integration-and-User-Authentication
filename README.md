# Database-Integration-and-User-Authentication

## Objective
Integrate database storage and implement secure user authentication.

## Technologies
- Node.js
- Express
- MongoDB
- JWT Authentication
- bcrypt Password Hashing

## Features
- User registration & login
- Encrypted passwords
- Token-based authentication
- Protected API routes
- Database storage

## How to Run
1. Start VS code
2. Open terminal
3. Run:
   npm install
   npm start
4. Open:
   http://localhost:3000

## Security
- JWT authorization
- Hashed passwords
- Protected endpoints
